BOBIK RUN — установка на iPhone + облачные сохранения
====================================================

Я подготовил файлы игры, PWA-установку, экран регистрации/входа через Supabase
и синхронизацию сохранений. Тебе останется создать облачный проект и вставить
его публичные настройки. Пароли и секретные ключи мне не отправляй.

1) SUPABASE
Открой https://supabase.com/ и создай проект на Free plan.

2) ТАБЛИЦА
В панели Supabase открой SQL Editor -> New query. Скопируй весь database.sql,
вставь в редактор и нажми Run. Таблица защищена RLS: пользователь читает и
меняет только собственное сохранение.

3) КЛЮЧИ
В Supabase открой Project Settings -> API. Скопируй Project URL и Publishable
key (или legacy anon key). Открой supabase-config.js и замени две строки
YOUR_SUPABASE_... на значения проекта. Не вставляй service_role/secret key.
Публичный anon/publishable key рассчитан на использование в клиентском приложении.

4) GITHUB PAGES
Создай публичный репозиторий на https://github.com/. Загрузи ВСЕ файлы из этой
папки в корень репозитория. Открой Settings -> Pages -> Deploy from a branch,
выбери main и /(root), затем Save. Дождись адреса вида
https://ТВОЙ-НИК.github.io/ИМЯ-РЕПОЗИТОРИЯ/

5) ПОДТВЕРЖДЕНИЕ EMAIL
В Supabase Authentication -> Providers -> Email оставь Email включённым.
При включённом подтверждении игрок после регистрации должен подтвердить почту
по письму, а затем войти. Встроенная отправка писем имеет лимиты; для публичного
проекта может понадобиться собственный SMTP.

6) ПРОВЕРКА
Открой опубликованную ссылку в Safari на iPhone. Создай тестовый аккаунт,
подтверди email, сыграй немного, обнови страницу и войди снова. Потом открой
игру на другом устройстве и войди в тот же аккаунт: сохранение должно загрузиться.

7) ИКОНКА НА iPHONE
Safari -> Поделиться -> На экран Домой -> Добавить.

ЧТО ВАЖНО ЗНАТЬ
- Это PWA, а не IPA и не приложение в App Store.
- Синхронизация и вход требуют интернет; гостевой режим хранит данные локально.
- Исходный код будет доступен в публичном GitHub-репозитории. Не клади туда
  пароли, приватные данные или секретные ключи.
- Supabase Free сейчас включает 500 MB базы и 50 000 активных пользователей
  в месяц; бесплатные проекты могут приостанавливаться после недели бездействия.
- Текущая игра загружает Three.js с CDN. Service Worker кеширует скрипты после
  первой онлайн-загрузки, но первый запуск должен быть с интернетом.
- Перед приглашением других игроков протестируй регистрацию, вход, выход,
  восстановление сохранения и работу на втором устройстве.
