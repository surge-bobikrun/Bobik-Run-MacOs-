BOBIK RUN v1.9.5 — ИСПРАВЛЕНИЕ RUN_ALREADY_ACTIVE
=====================================================

Основа сборки: Bobik Run v1.9.7.
Номер версии: v1.9.5.

Дополнительно исправлен запуск облачных забегов: экран выбора режима больше не
создаёт забег заранее. Повторный запрос старта с тем же режимом и сложностью
возвращает ID уже созданной активной сессии вместо RUN_ALREADY_ACTIVE.

ЧТО ИЗМЕНИЛОСЬ ПО ЗАМЕЧАНИЯМ К v1.9.7
--------------------------------------

1. Ноги полностью убраны; персонаж сливается с транспортом как в игре
- В 3D-предпросмотре профиля больше нет никаких ног.
- Найдена настоящая причина «неслияния»: в игре setV() опускает персонажа на
  величину, зависящую от машины ([0, -0.1, -0.3, -0.15] для Цистерны, Гориллы,
  Бобика и Банана) — именно поэтому в игре и магазине машина с персонажем
  выглядят единым целым. Функция сборки копий (BobikBuildFavoriteModels) стирала
  этот офсет, и предпросмотр пересаживал персонажа «на крышу».
- Теперь офсет сохраняется: персонаж и машина — сиблинги с тем же смещением,
  что в игре. Предпросмотр показывает ТОТ ЖЕ силуэт, что и магазин/игра.
- Проверено геометрически: для всех четырёх машин смещение совпадает с игровым.

2. У всех в предпросмотре — то, что на них надето
- Свой профиль: текущие cfg.ch/cfg.vh (то, что выбрано прямо сейчас).
- Публичные профили: колонки favorite_character/favorite_vehicle из public_profiles,
  синхронизируются при выборе в магазине, при любом сохранении прогресса и на
  экране профиля — у каждого игрока видны именно его выбранные модельки.
- Новой миграции не требуется (колонки добавлены миграцией v1.9.5/1.9.6).

3. Убрана большая задержка трансляции
- Если Realtime-канал недоступен (выключён в проекте, блокировка сети и т.п.),
  раньше админ видел только медленную карточку-телеметрию (обновление ~2.5–4.5 с).
- Теперь снимок состояния (spectate) сам превращается в кадр и питает ТА ЖЕ
  3D-сцену трансляции: опрос каждые 0.7 с, плавная интерполяция движения.
- Публикация состояния игрока ускорена с 2 до 1 секунды — «кто в забеге» живее.
- Индикатор статуса честно показывает источник: «🔴 ПРЯМАЯ ТРАНСЛЯЦИЯ · задержка
  ~N мс» по каналу или «🔴 ТРАНСЛЯЦИЯ · обновление ~0.7 с (Realtime-канал
  недоступен)» по снимкам. Задержка по каналу не показывает абсурдные числа при
  расхождении часов устройств.
- Если игрок вышел из забега — сцена корректно сменяется статус-карточкой.

4. Экран смерти сокращён
- После «⭐ Получено XP» убрана вся остальная статистика: прогресс уровня,
  режим, сложность, рекорды, «до рекорда», время, средняя скорость.
- Остались: пройденная дистанция, монеты за забег, полученный XP, сообщение
  администратора (если останавливал забег) и разовые события (награда охоты,
  ошибка подтверждения сервера) — они приходят отдельно и только когда случаются.

СОХРАННОСТЬ
-----------
- Не удаляются аккаунты, покупки, прогресс, рекорды и настройки.
- Миграции БД не требуются (достаточно применённых ранее).

ПРОВЕРКИ
--------
- Синтаксис всех встроенных JavaScript-блоков проверен.
- В headless-браузере: смещение персонажа совпадает с игровым на 4 машинах,
  сцена трансляции строится и для кадров канала, и для REST-снимков (статус
  переключается корректно), экран смерти содержит только дистанцию/монеты/XP,
  навигация по экранам без ошибок страницы.
- Полноценный запуск на Android и проверка в реальных аккаунтах требуют целевой среды.
